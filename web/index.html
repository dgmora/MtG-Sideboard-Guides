Sideboard Guide

How this works

This page turns a sideboard guide kept in Google Sheets into a card you can print and keep in your deck box.

Keep one spreadsheet with a tab per deck, named after the deck. Start from a copy of the template, or convert the guide you already have with the prompt below. Share the spreadsheet as "Anyone with the link can view" and add its link above: every tab becomes a guide. Edit the sheet and the card catches up within a minute, or right away when you press Reload.

Everything happens in your browser: we never see or store your spreadsheet. This page only remembers your links and the guide you picked last, on this device.

Guide in another format?

An AI assistant like Claude or ChatGPT can convert it. Copy this prompt into a chat, then paste or upload your guide and your decklist with it: text, CSV, Excel or screenshots should all work.

It replies with a CSV to import into a tab of your spreadsheet (File → Import) and a link that opens the guide on this page. Check that the link starts with this page's address before you open it.

Convert the sideboard guide I'm attaching into a CSV for my Magic: The Gathering deck. I'm also attaching my decklist.

Layout:
- First row: md,sb,Card, then one column per matchup, named after the opposing deck. If the guide differs on the play and on the draw, use two columns, like "Goblins (play)" and "Goblins (draw)".
- Then one row per card that goes in or out in any matchup: copies in the main deck (md), copies in the sideboard (sb), the card name as written in the decklist, then the change in each matchup.
- Main deck cards first, then one empty row, then sideboard cards. A card in both the main deck and the sideboard gets a single row in the main deck part, with both counts.
- Changes are whole numbers: 2 brings in two copies, -1 takes one out. Never write a + sign. Leave the cell empty when nothing changes.
- Add * after the number when the guide marks a swap as optional, like 1* or -1*.
- No total row. Put quotes around any value that contains a comma.
- Each matchup should bring in as many cards as it takes out. If the guide doesn't, keep what it says and tell me.

Reply with:
1. The CSV as a downloadable sideboard.csv file, which I'll import into Google Sheets. If you can't create files, put it in a code block instead.
2. This link with the CSV URL-encoded at the end: ?paste=
Write line breaks as %0A, spaces as %20, % as %25, + as %2B, & as %26, # as %23, " as %22, ( as %28 and ) as %29. Use a code tool for this if you have one.
